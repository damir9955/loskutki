> **Версия 2.4.0** — комнаты в **Deno KV**: партии переживают перезапуск и передеплой сервера (игрок возвращается по коду комнаты — и партия на месте); одновременные ходы из разных регионов не теряются (запись по CAS).
>
> **Версия 2.3.0** — стабильный онлайн: мультиплеер переведён с поллинга Vercel на WebSocket-сервер **Deno Deploy** (ходы соперника приходят мгновенно, обрывы связи лечатся авто-переподключением). Сервер — один файл `deno/server.ts`, разворачивается бесплатно за 5 минут (см. ниже). Без переменной `NEXT_PUBLIC_WS_URL` игра работает по-старому через API-роуты.

>
> **Версия 2.0.0** (10 сентября 2026) — быстрая игра (автопоиск), возврат в партию, новые иконки и логотип.

Мобильная/планшетная игра по мотивам настольного **Patchwork** (Uwe Rosenberg): сшивайте лоскутное полотно 9×9, соревнуясь с ботом или живым соперником онлайн. Весь геймплей — на одном экране, без скролла, с прямым перетаскиванием лоскутков пальцем.

## Игровые особенности

- 🎮 **Одна кнопка «Играть»** — Casual или Ежедневный вызов (одинаковый расклад для всех в этот день)
- 🤖 **Три уровня бота**: Новичок, Мастер, Гроссмейстер
- 👥 **«С другом»** — комната по 6-значному коду, открытые комнаты в поиске и ⚡ **Быстрая игра** (автопоиск); возврат в партию из хаба; до 3 минут на ход с авто-шагом при просрочке
- 📱 **Планшет**: вертикально — та же телефонная вёрстка; горизонтально — полотно-доминанта, компактная дорожка времени и соперник, крупные карточки рынка, всё без прокрутки
- 🧩 **33 лоскутка-полимино** с ценой в пуговицах, временем и доходом
- ⏱️ **Дорожка времени 0–53** с наградами на клетках и кожаными лоскутками 1×1
- 🎁 **Бонус 7×7**: первым закрыть область 7×7 — получить особую пуговицу
- 🏆 **Финальный счёт**: −2 за пустые клетки, доход × оставшееся время, реванш в один тап (онлайн — по согласию обоих)
- 🔊 Звук, вибрация, статистика побед и достижения — офлайн-режим полностью на устройстве

## Технологии

- [Next.js 16](https://nextjs.org/) (App Router) + React 19
- TypeScript, Tailwind CSS 4
- Собственный игровой движок (`src/lib/game/`): RNG с сидом, бот с эвристиками, валидация раскладки полимино
- Иконки и шрифты (Nunito / Yeseva) лежат локально в `public/` — внешних запросов нет

## Деплой на Vercel

1. Загрузите этот проект в репозиторий GitHub.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → импортируйте репозиторий.
3. Настройки менять не нужно — Vercel сам определит Next.js. Нажмите **Deploy**.

## Запуск мультиплеер-сервера (Deno Deploy, бесплатно)

Клиент остаётся на Vercel, а комнаты живут на отдельном WebSocket-сервере —
без «засыпаний» и таймаутов, доступном из России без VPN.

1. Зарегистрируйтесь на [dash.deno.com](https://dash.deno.com) (через GitHub, без карты).
2. **New Playground** → удалите содержимое `main.ts` → вставьте **весь** файл
   `deno/server.ts` из этого репозитория → **Save & Deploy**.
3. Получите адрес вида `https://<имя>.deno.dev`. Откройте его в браузере —
   увидите страницу «Лоскутки: сервер онлайн».
4. В настройках Vercel: **Settings → Environment Variables → Add**:
   - Name: `NEXT_PUBLIC_WS_URL`
   - Value: `wss://<имя>.deno.dev`

   Затем **Deployments → Redeploy**.
5. Готово: ходы соперника приходят мгновенно, при обрыве связи игра сама
   переподключается (15 секунд), прогресс не теряется.

Обновлять сервер — просто отредактировать код в Playground и нажать
**Save & Deploy** снова. Комнаты хранятся в **Deno KV**: перезапуск и
передеплой сервера НЕ закрывают активные партии — игроки возвращаются
по коду комнаты (сессия хранится в браузере) и продолжают с того же места.
Запись ходов идёт по CAS (versionstamp) — одновременные ходы игроков
из разных регионов не перетирают друг друга. Локально (без флага
`--unstable-kv`) сервер работает в режиме оперативной памяти.

Локально можно поднять реплику для тестов: `bun scripts/run-server-bun.ts`
(тот же протокол, порт 8081) и `.env.local` с
`NEXT_PUBLIC_WS_URL=ws://localhost:8081`.

## Переменные окружения

- `NEXT_PUBLIC_WS_URL` — адрес WebSocket-сервера (например `wss://loskutki.deno.dev`).
  Пусто/не задана → онлайн работает через API-роуты Vercel (запасной режим).
- `MP_TURN_MS` — время на ход в миллисекундах (по умолчанию 180000 = 3 мин; для тестов). Работает и на Vercel, и на Deno Deploy.
- `LOSKUTKI_MP_STORE` — путь снапшота комнат для запасного режима (по умолчанию `.mp-rooms.json`).

## Структура

```
deno/server.ts        # WebSocket-сервер мультиплеера (Deno Deploy) — весь онлайн
src/
  app/               # страница-обёртка, стили, API онлайн-комнат (api/mp/*, запасной режим)
  components/game/   # GameScreen, QuiltBoard, TimeTrack, MarketRow, Multiplayer, ...
  lib/game/          # движок: engine, bot, placement, outline, rng
  lib/server/        # комнаты запасного режима (rooms.ts, roomStore.ts)
  lib/ws.ts          # WebSocket-клиент: авто-reconnect, watchdog, мгновенные push
  lib/net.ts         # сетевой слой: сокет или API-роуты — одинаковые функции
public/              # иконки, шрифты, manifest (PWA)
```
