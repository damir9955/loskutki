> **Версия 3.3.1** — ПОЧИНЕН ДЕПЛОЙ сервера на console.deno.com.
>
> Если у вас деплой падал на этапах **«Warm up (Failed)»** и
> **«Register crons (Failed)»** — причина найдена и исправлена: старый
> сервер поднимал HTTP-сервер только при `import.meta.main`, а новая
> платформа запускает входную точку через собственную обёртку
> (main=false) — сервер не поднимался вовсе. Теперь он поднимается под
> любым Deno всегда, а отказ `openKv` без подключённой базы больше не
> убивает изолят (перехват незахваченных rejection). Протестировано
> локально на Deno 2.5.0 (версия платформы) во всех режимах: с базой
> и без, как main и как импорт.
>
> **Что делать, если v3.3.0 не задеплоился:** откройте свой Playground
> на console.deno.com → выделите весь код → вставьте **весь** файл
> `deno/server.ts` из ЭТОГО архива (v3.3.1) → **Deploy** — все этапы
> должны позеленеть. Сайт (клиент) можно не обновлять; архив обновлён
> до v3.3.1 целиком для новых установок.

## Игровые особенности

- 🎮 **Одна кнопка «Играть»** — Casual или Ежедневный вызов (одинаковый расклад для всех в этот день)
- 🤖 **Три уровня бота**: Новичок, Мастер, Гроссмейстер
- 👥 **«С другом»** — комната по 6-значному коду, открытые комнаты в поиске и ⚡ **Быстрая игра** (автопоиск); возврат в партию из хаба; до 3 минут на ход с авто-шагом при просрочке
- 📱 **Планшет**: вертикально — колонка почти на всю ширину, соперник — четвёртой карточкой в ряду рынка; горизонтально — полотно-доминанта, соперник и крупные карточки рынка в одной колонке, полоса (дорожка + показатели + «Шагнуть») заполнена целиком, всё без прокрутки
- 🧩 **33 лоскутка-полимино** с ценой в пуговицах, временем и доходом
- ⏱️ **Дорожка времени 0–53** с наградами на клетках и кожаными лоскутками 1×1
- 🎁 **Бонус 7×7**: первым закрыть область 7×7 — получить особую пуговицу
- 🏆 **Финальный счёт**: −2 за пустые клетки, доход × оставшееся время, реванш в один тап (онлайн — по согласию обоих)
- 🔊 Звук, вибрация, статистика побед и достижения — офлайн-режим полностью на устройстве

## Технологии

- [Next.js 16](https://nextjs.org/) (App Router) + React 19
- TypeScript, Tailwind CSS 4
- Собственный игровой движок (`src/lib/game/`): RNG с сидом, бот с эвристиками, валидация раскладки полимино
- Иконки и шрифты (Nunito / Yeseva) лежат локально в `public/` — внешних запросов нет

## Деплой на Vercel

1. Загрузите этот проект в репозиторий GitHub.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → импортируйте репозиторий.
3. Настройки менять не нужно — Vercel сам определит Next.js. Нажмите **Deploy**.

## Как ОБНОВИТЬ уже задеплоенную игру (и проверить, что обновление встало)

1. **РАСПАКУЙТЕ** архив и загружайте в GitHub **файлы проекта** из папки
   `loskutki` (НЕ сам .zip!). Через сайт GitHub: **Add file → Upload files** —
   перетащите туда всё содержимое папки `loskutki`, старые файлы заменятся.
   Через git: скопируйте файлы поверх, закоммитьте и запушьте.
2. Дождитесь, пока Vercel соберёт проект (Deployments → статус **Ready**).
3. **Проверка деплоя**: откройте в браузере `https://ВАШ-САЙТ/version.json` —
   должно быть `"version": "3.3.1"`. Показывает старую версию или 404 —
   деплой не прошёл: смотрите **Deployments → Logs** в Vercel.
4. На телефоне: зайдите в игру с интернетом → **Настройки → внизу «Версия
   сборки»**. Если там ещё старая версия — полностью закройте игру/вкладку и
   откройте снова: при запуске игра сверяется с сервером и при
   необходимости сама перекачивает обновление.

## Запуск мультиплеер-сервера (НОВЫЙ Deno Deploy, бесплатно)

⚠️ **Старая платформа dash.deno.com закрыта 20.07.2026.** Всё делается
на новой консоли [console.deno.com](https://console.deno.com).

Клиент остаётся на Vercel, а комнаты живут на отдельном WebSocket-сервере —
без «засыпаний» и таймаутов, доступном из России без VPN.

1. Зайдите на [console.deno.com](https://console.deno.com) (вход через
   GitHub, без карты) → создайте организацию, если попросит.
2. **Applications → New Playground** → удалите содержимое `main.ts` →
   вставьте **весь** файл `deno/server.ts` из этого репозитория →
   **Deploy**. Внизу в **BUILD LOGS** все шаги должны позеленеть
   (этап Warm up проходит всегда — сервер в v3.3.1 поднимается
   мгновенно, база подключается уже после).
3. **Подключите базу (один раз)** — иначе после паузы сервер забудет
   комнаты и друзей: настройки приложения (шестерёнка/Settings) →
   **Databases → Attach Database → Provision Database** → движок
   **Deno KV** → регион → **Create**. Сервер подхватит её сам при
   следующем запуске (на странице «сервер онлайн» появится строка
   «Хранение: Deno KV»).
4. Скопируйте адрес из шапки редактора (вида `https://<имя>...`) и
   впишите его в игре: **Настройки → «Сервер онлайн-игры» →
   Сохранить**. Альтернатива для «на всю сборку»: на Vercel
   **Settings → Environment Variables → Add** → `NEXT_PUBLIC_WS_URL` =
   `https://<имя>...` → **Deployments → Redeploy**.
5. Проверка: откройте адрес сервера в браузере — увидите страницу
   «Лоскутки: сервер онлайн». Ходы соперника приходят мгновенно, при
   обрыве связи игра сама переподключается, прогресс не теряется.

Обновлять сервер — просто отредактировать код в Playground и нажать
**Deploy** снова. Комнаты хранятся в **Deno KV** (после шага 3):
перезапуск и передеплой сервера НЕ закрывают активные партии — игроки
возвращаются по коду комнаты (сессия хранится в браузере) и
продолжают с того же места. Запись ходов идёт по CAS (versionstamp) —
одновременные ходы игроков из разных регионов не перетирают друг
друга. Локально (без флага `--unstable-kv`) сервер работает в режиме
оперативной памяти.

Локально можно поднять реплику для тестов: `bun scripts/run-server-bun.ts`
(тот же протокол, порт 8081) и `.env.local` с
`NEXT_PUBLIC_WS_URL=ws://localhost:8081`.

## Переменные окружения

- `NEXT_PUBLIC_WS_URL` — адрес WebSocket-сервера (например `https://имя.deno.net`).
  Пусто/не задана → онлайн работает через API-роуты Vercel (запасной режим).
  Приоритет: адрес из Настроек игры («Сервер онлайн-игры») → эта переменная.
- `MP_TURN_MS` — время на ход в миллисекундах (по умолчанию 180000 = 3 мин; для тестов). Работает и на Vercel, и на Deno Deploy.
- `LOSKUTKI_MP_STORE` — путь снапшота комнат для запасного режима (по умолчанию `.mp-rooms.json`).

## Структура

```
deno/server.ts        # WebSocket-сервер мультиплеера (Deno Deploy) — весь онлайн
src/
  app/               # страница-обёртка, стили, API онлайн-комнат (api/mp/*, запасной режим)
  components/game/   # GameScreen, QuiltBoard, TimeTrack, MarketRow, Multiplayer, ...
  lib/game/          # движок: engine, bot, placement, outline, rng
  lib/server/        # комнаты запасного режима (rooms.ts, roomStore.ts)
  lib/ws.ts          # WebSocket-клиент: авто-reconnect, watchdog, мгновенные push
  lib/net.ts         # сетевой слой: сокет или API-роуты — одинаковые функции
public/              # иконки, шрифты, manifest (PWA)
```
