ЛОСКУТКИ — сборка v3.5.0 от 15.09.2026
===============================================

ЭТОТ ФАЙЛ — ПРОСТАЯ ПРОВЕРКА, ЧТО ПЕРЕД ВАМИ НОВАЯ СБОРКА.
Если вы распаковали архив и видите здесь v3.5.0 — файлы свежие.

Что нового в этой сборке (v3.5.0 — хранилище БЕЗ Deno KV):
1. СЕРВЕР УМЕЕТ РАБОТАТЬ БЕЗ KV-БАЗЫ DENO. Если бесплатная KV-база
   Deno Deploy занята другим проектом (на бесплатном плане их всего
   ОДНА), теперь есть выход: бесплатная база Cloudflare D1 — без
   карты, работает из России, подключается ТРЕМЯ переменными
   окружения в Playground (D1_ACCOUNT_ID, D1_DATABASE_ID, D1_API_TOKEN).
   Комнаты, друзья, переписка и ID игроков переживают перезапуск
   точно так же, как с Deno KV. Пошаговая инструкция — в шапке файла
   loskutki-deno-server-v3.5.0.ts и в README (раздел «Хранилище»).
2. ПРИОРИТЕТ ХРАНИЛИЩА: Cloudflare D1 (если заданы D1_*) → Deno KV
   (если база подключена) → оперативная память. Если ничего не
   подключено — сервер честно работает и предупреждает в игре.
3. ЗАПАСНОЙ ХОСТИНГ СЕРВЕРА: в архив добавлены Dockerfile.server и
   render.yaml — если Deno Deploy когда-нибудь станет недоступен,
   сервер за один клик разворачивается на Render.com (бесплатный
   план, без карты). Подойдёт и Koyeb. Сайт игры при этом остаётся
   на Vercel — ничего не меняется.
4. МЕНЬШЕ ЛИШНИХ ЗАПИСЕЙ: для внешней базы интервалы «присутствия»
   растянуты (записей в разы меньше при тех же индикаторах «на
   связи»/«в сети»); индикатор «на связи» теперь учитывает живой
   сокет игрока, а не только свежесть записи в базе.
5. ПРОВЕРЕНО: полный прогон тестов на реальном SQL (мок D1),
   рестарт-тест с kill -9 (друзья/чат/комната пережили), смоук
   настоящего Deno-сервера, деградация (нет базы → память; база
   недоступна → не падает, честное предупреждение).

ВАЖНО: чтобы новые возможности заработали, ОБНОВИТЕ И СЕРВЕР —
замените код в Playground (console.deno.com) на файл
loskutki-deno-server-v3.5.0.ts и, если хотите подключить D1,
добавьте три переменные окружения (инструкция в README и в шапке
файла сервера).

Как проверить после загрузки на GitHub/Vercel:
1) Откройте https://ВАШ-САЙТ/version.json — версия должна быть 3.5.0.
2) В игре: Настройки → внизу «Версия сборки: v3.5.0».
3) Адрес сервера в браузере — строка «Хранение» покажет, какая база
   подключена (Cloudflare D1 / Deno KV / память).

Полный список изменений — в README.md.
